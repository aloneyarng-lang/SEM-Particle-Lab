# SEM Particle Lab 4.0

SEM 颗粒测量、标注及粒径分布统计工具。

## 目录结构

- `开始标注.bat`: Windows 双击启动脚本
- `开始标注.command`: macOS 双击启动脚本
- `input/`: 存放 SEM 原图（TIF/TIFF/PNG/JPG/BMP/WebP）
- `output/`: 保存所有测量数据和图表导出文件
- `app/`: 程序核心文件（无需手动打开）

## 环境要求与启动

1. **运行环境**：需本机安装 **Python 3.9 或更高版本**（仅依赖 Python 标准库，**不需要额外安装 pip 第三方包**）。
2. **Windows 启动**：双击运行 `开始标注.bat`。
3. **macOS 启动**：双击运行 `开始标注.command`（首次打开若有系统安全提醒，可右键选择“打开”，或从终端运行 `bash 开始标注.command`）。
4. 程序会在默认浏览器中自动打开（如未自动打开，可复制控制台显示的 `http://127.0.0.1:...` 本地地址）。
5. 数据仅在本机运行处理，关闭终端窗口即可停止程序。

## 使用流程

1. **导入图像**：将图片放入 `input` 文件夹，在页面顶部下拉列表选择图片后点击“打开”；也可直接点击“导入图像”。
2. **标定与设置**：检查/修改标定值、黑白阈值和底部信息栏排除高度。
3. **识别统计**：点击“识别并统计颗粒”，使用轮廓识别与二轮扫描。
4. **颗粒复核**：在右侧按编号检查颗粒：
   - `↑` / `↓`：选择上/下一个颗粒
   - `空格`：切换纳入状态
   - `Delete` / `Backspace` / `X`：排除颗粒
   - `A`：恢复纳入
5. **圆度批量过滤**：输入圆度下限（默认 0.90）并点击“排除圆度 < ...”，剔除非球形杂质或连通颗粒。
6. **导出数据与图表**：
   - 导出标注 PNG、颗粒 CSV、统计 CSV、全部统计图 PNG；
   - 论文风格双纵轴图可单独导出高清 PNG 和 SVG；
   - 导出文件自动保存至 `output` 文件夹，已存在的同名文件会自动增加序号保留。

## 说明

- 原图底部信息栏只在识别时排除，原图和导出图仍保留原始信息栏。
- SEM 图像为二维投影，Dv50 和体积分数为球形假设下的 $d^3$ 加权估计。
- 所有数据与计算均在本地完成，不会上传到外部服务器。
- 如果机器未安装 Python 3，也可直接在浏览器中双击打开 `app/index.html`，但需通过浏览器手动导入图片与下载导出文件。
