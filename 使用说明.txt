SEM Particle Lab 4.0 · SEM 颗粒测量、标注及粒径分布统计

【目录】
开始标注.command   Mac 双击启动
开始标注.bat       Windows 双击启动
input/             存放 SEM 原图（TIF/TIFF/PNG/JPG/BMP/WebP）
output/            保存所有测量数据和图表导出文件
app/               程序核心文件（无需手动打开）

【启动】
1. 需本机安装 Python 3.9 或更高版本（不需要安装 pip 第三方包）。
2. Mac 双击「开始标注.command」；Windows 双击「开始标注.bat」。
3. 程序会在默认浏览器自动打开，数据只在本机处理，不需要网络服务。
4. 如果浏览器没有自动打开，请复制终端中 http://127.0.0.1:... 的地址。
5. 关闭启动项所在终端窗口就会停止程序。

Mac 第一次双击 .command 若出现系统安全提醒：可右键选择“打开”，
或者从终端在文件夹中运行 bash "开始标注.command"。

【流程】
1. 将图片放进 input 文件夹，在页面顶部下拉列表选择图片，再点“打开”。
   也可以直接点“导入图像”，程序会把导入的原图复制到 input 文件夹。
2. 检查/修改标定值、黑白阈值和底部信息栏排除高度。
3. 点击“识别并统计颗粒”，使用普通轮廓识别+可选二轮扫描。
4. 在右侧按编号检查颗粒。↑ / ↓ 选择上/下一个；空格 切换纳入；
   Delete / Backspace / X 排除；A 恢复纳入。
5. 圆度下限默认 0.90，可输入 0 到 1 的值后点击“排除圆度 < ...”。
   仅针对圆度有效且当前纳入的颗粒执行，圆度空值不做过滤；
   “撤销批量过滤”不恢复其他手动排除的颗粒。
6. 导出标注 PNG、颗粒 CSV、统计 CSV、全部统计图 PNG；
   论文风格双纵轴图可单独导出高清 PNG 和 SVG。
7. 所有导出自动进入 output 文件夹，已存在的同名文件会自动加序号保留。

【说明】
- 原图底部信息栏只在识别时排除，原图和导出图仍保留原始信息栏。
- 取消了灰度辅助分离识别分支；灰度/对比度仍可用于二值化预处理。
- SEM 图像是二维投影；Dv50 和体积分数为球形假设下的 d³ 加权估计。
- 输入 / 输出只在本机进行，不会上传到外部服务器。
- 文件夹可以整体移动或复制到 Mac/Windows；不同系统使用对应启动项。
- 如果机器没有 Python 3，也可以直接在浏览器打开 app/index.html，
  但无法自动读取 input 或把结果保存到 output，只能浏览器手动导入/下载。
